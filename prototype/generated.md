# Executable documentation: proof of concept

Generated by `uv run --project . python prototype/run.py`. Named source blocks come directly from the existing documentation; responses come from compiled stories running in console Glulxe with CheapGlk. The runner echoes submitted commands and removes its input-boundary markers. Compiler versions, random seed, and build date are fixed.
